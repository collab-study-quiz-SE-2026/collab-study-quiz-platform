1. EXECUTIVE OVERVIEW & PROJECT CONTEXT
--------------------------------------------------------------------------------
The Collaborative Study Material & Quiz Platform (CSMQP) is a full-stack, 3-tier
web platform designed for higher education students to share study materials,
collaborate on question banks, conduct real-time multiplayer and practice quizzes,
and evaluate longitudinal topic-level learning analytics.

Architectural Stack:
- Presentation Tier : React + Vite + TypeScript Single Page Application (SPA).
- Service/API Tier  : FastAPI (REST & WebSockets) running on Python 3.12+ (or 3.14).
- Data Tier         : PostgreSQL 15 (relational), SQLAlchemy 2 (ORM), Alembic (migrations),
                      and S3-compatible object storage (RustFS).
- Ingress/Security  : Caddy reverse proxy enforcing TLS 1.3, Bcrypt (cost >= 12)
                      password hashing, HS256 stateless 60-min JWT authentication
                      with token version invalidation, and strict SQL parameter binding.

Milestone Context:
- Foundation (Epic #20 / Story #21): Local Docker infrastructure, TLS proxy, and health checks.
- Epic #1 (Authentication & RBAC, PR #44): 'users' table, registration, login, logout revocation.
- Epic #10 (Collaborative Question Bank):
  * Story #11 (Issue #11): "Create Questions" (5 Story Points, Sprint 1, Priority: High).
  * Objective: Allow authenticated students to contribute validated multiple-choice questions
    to a shared question pool, and store/retrieve submitted questions.


2. ACCEPTANCE CRITERIA & HOW EACH WAS FULFILLED
--------------------------------------------------------------------------------
Criteria 1: "Authenticated students can create multiple-choice questions."
-> Fulfilled: The endpoint POST /questions (and POST /api/v1/questions) requires a valid
   JWT Bearer token via FastAPI dependency injection `Depends(get_current_user)`.
   The authenticated user's ID is automatically bound to the question's `creator_id`.
   Unauthenticated requests are rejected with HTTP 401 Unauthorized.

Criteria 2: "Each question includes question text, answer options and the correct answer."
-> Fulfilled: The Question model and QuestionCreate schema require:
   - question_text (the question prompt)
   - options (exactly 4 multiple-choice options)
   - correct_answer_index (0-based integer referring to the correct option index)
   - topic (e.g. DBMS, OS, Networks)
   - difficulty (easy, medium, hard)
   - explanation (optional rationale / study explanation)

Criteria 3: "Required fields are validated."
-> Fulfilled: Pydantic validators enforce:
   - Non-blank question_text and topic (whitespace is stripped; empty string raises error).
   - Exactly 4 options (min_length=4, max_length=4).
   - No blank options inside options list (whitespace is stripped).
   - correct_answer_index must be >= 0 and strictly less than len(options).
   - difficulty must be one of "easy", "medium", or "hard".
   - Malformed payloads return standard HTTP 422 Unprocessable Entity.

Criteria 4: "Submitted questions are stored and retrievable."
-> Fulfilled:
   - Stored in PostgreSQL table `questions` via SQLAlchemy 2 ORM with foreign key
     to `users.id` (ON DELETE CASCADE) and index on `topic` and `creator_id`.
   - Migration tracked via Alembic revision `20261101_0002_create_questions_table`.
   - Retrievable via:
     * GET /questions (with query filters: topic, difficulty, creator_id, limit, offset)
     * GET /questions/{question_id} (single question retrieval; 404 if not found)
     * GET /questions/search?topic=... (dedicated search endpoint aligned with IEEE TC-05)

from app.database import Base


class UserRole(str, Enum):
    STUDENT = "student"
    MODERATOR = "moderator"


class User(Base):
    __tablename__ = "users"
    __table_args__ = (
        UniqueConstraint("email"),
        Index("ix_users_email", "email"),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(320))
    password_hash: Mapped[str] = mapped_column(String(60))
    role: Mapped[UserRole] = mapped_column(
        SqlEnum(UserRole, name="user_role"), default=UserRole.STUDENT
    )
    token_version: Mapped[int] = mapped_column(default=0)

    questions: Mapped[list["Question"]] = relationship("Question", back_populates="creator")


class Question(Base):
    __tablename__ = "questions"
    __table_args__ = (
        Index("ix_questions_topic", "topic"),
        Index("ix_questions_creator_id", "creator_id"),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    question_text: Mapped[str] = mapped_column(Text)
    options: Mapped[list[str]] = mapped_column(JSON)
    correct_answer_index: Mapped[int] = mapped_column(Integer)
    topic: Mapped[str] = mapped_column(String(100))
    difficulty: Mapped[str] = mapped_column(String(20), default="medium")
    explanation: Mapped[str | None] = mapped_column(Text, nullable=True)
    creator_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"))
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), default=lambda: datetime.now(UTC)
    )

    creator: Mapped["User"] = relationship("User", back_populates="questions")

    context.configure(
        url=engine.url,
        target_metadata=target_metadata,
        literal_binds=True,
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online():
    with engine.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()

class QuestionCreate(BaseModel):
    question_text: str = Field(min_length=1)
    options: list[str] = Field(min_length=4, max_length=4)
    correct_answer_index: int = Field(ge=0)
    topic: str = Field(min_length=1)
    difficulty: Literal["easy", "medium", "hard"] = "medium"
    explanation: str | None = None

    @field_validator("question_text", "topic", mode="before")
    @classmethod
    def strip_required_text(cls, value: object) -> object:
        if isinstance(value, str):
            return value.strip()
        return value

    @field_validator("question_text", "topic")
    @classmethod
    def reject_blank_text(cls, value: str) -> str:
        if not value:
            raise ValueError("must not be blank")
        return value

    @field_validator("options", mode="before")
    @classmethod
    def strip_options(cls, value: object) -> object:
        if isinstance(value, list):
            return [option.strip() if isinstance(option, str) else option for option in value]
        return value

    @field_validator("options")
    @classmethod
    def reject_blank_options(cls, value: list[str]) -> list[str]:
        if any(not option for option in value):
            raise ValueError("options must not be blank")
        return value

    @model_validator(mode="after")
    def correct_answer_is_an_option(self) -> "QuestionCreate":
        if self.correct_answer_index >= len(self.options):
            raise ValueError("correct_answer_index must refer to an option")
        return self


class QuestionResponse(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int

    options: list[str]
    correct_answer_index: int
    topic: str
    difficulty: str
    explanation: str | None = None

    created_at: datetime


class QuestionListResponse(BaseModel):

    items: list[QuestionResponse]

@app.post(
    "/auth/register",
    response_model=RegistrationResponse,
    status_code=status.HTTP_201_CREATED,
)
def register(details: RegistrationRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    if db.scalar(select(User).where(User.email == email)) is not None:
        raise HTTPException(status_code=409, detail="An account with this email already exists")

    user = User(email=email, password_hash=hash_password(details.password))
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"message": "Registration successful", "user": user}


@app.post("/auth/login", response_model=TokenResponse)
def login(details: LoginRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    user = db.scalar(select(User).where(User.email == email))
    if user is None or not verify_password(details.password, user.password_hash):
        raise HTTPException(status_code=401, detail="Incorrect email or password")

    return {"access_token": create_access_token(user), "token_type": "bearer"}


@app.post("/auth/logout", response_model=MessageResponse)
def logout(
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    current_user.token_version += 1
    db.commit()
    return {"message": "Logged out successfully"}


@app.get("/auth/me", response_model=UserResponse)
def read_current_user(current_user: User = Depends(get_current_user)):
    return current_user


@app.get("/auth/users/{user_id}", response_model=UserResponse)
def read_user(
    user_id: int,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    if current_user.id != user_id and current_user.role != UserRole.MODERATOR:
        raise HTTPException(status_code=403, detail="You can only access your own account")

    user = db.get(User, user_id)
    if user is None:
        raise HTTPException(status_code=404, detail="User not found")
    return user

@app.get(
    "/api/v1/questions/search",
    response_model=list[QuestionResponse],
    include_in_schema=False,
)
def search_questions(
    topic: str | None = None,
    difficulty: str | None = None,
    db: Session = Depends(get_db),
):
    stmt = select(Question)
    if topic:
        stmt = stmt.where(Question.topic == topic)
    if difficulty:
        stmt = stmt.where(Question.difficulty == difficulty)
    stmt = stmt.order_by(Question.id.desc())
    return list(db.scalars(stmt).all())

def list_questions(
    topic: str | None = None,
    difficulty: str | None = None,
    creator_id: int | None = None,
    limit: int = 50,
    offset: int = 0,
    db: Session = Depends(get_db),
):
    stmt = select(Question)
    if topic:

    if difficulty:

    stmt = stmt.order_by(Question.id.desc()).offset(offset).limit(limit)
    return list(db.scalars(stmt).all())


@app.websocket("/ws/health")
async def websocket_health(websocket: WebSocket):
    origin = websocket.headers.get("origin")
    if origin is not None and origin not in frontend_origins:
        await websocket.close(code=1008)
        return

    await websocket.accept()
    try:
        while True:
            message = await websocket.receive_text()
            await websocket.send_text("pong" if message == "ping" else "Send ping")
    except WebSocketDisconnect:
        pass
