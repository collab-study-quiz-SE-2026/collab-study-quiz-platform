1. EXECUTIVE SUMMARY & OBJECTIVES
--------------------------------------------------------------------------------
This PR fulfills all functional and non-functional requirements for Issue #19:
"STORY: Visualize Learning Progress".

User Story:
"As a student, I want to see visual representations of my quiz performance over
time so that I can monitor my learning progress."

Key Capabilities Delivered:
1. Chronological timeline of quiz attempts with score progression, cumulative
   moving averages, and trajectory tracking (improving, declining, stable).
2. Overall learning progress summary indicators: total quizzes completed, average
   score, highest and lowest scores, initial score, latest score, and net improvement delta.
3. Topic-wise performance trends over time, tracking accuracy evolution per topic across attempts.
4. Interactive, responsive SVG learning progress visualization chart component
   (`frontend/src/components/LearningProgressChart.tsx`) featuring hover tooltips,
   moving-average trend lines, KPI summary cards, and topic drill-downs.
5. Graceful empty state handling for students with limited or zero completed attempts.
6. Server-side RBAC: students can only view their own progress (403 Forbidden for
   unauthorized student access); moderators can inspect any student's progress.
7. Sub-second response time (<600 ms, NFR-01) with eager relationship loading (`selectinload`).

3. ARCHITECTURAL DESIGN & DATA ACCESS PATTERN
--------------------------------------------------------------------------------
Backend Aggregation:
- Uses SQLAlchemy 2 `selectinload` for eager-loading `QuizAttempt.quiz` -> `Quiz.questions`
  -> `QuizQuestion.question`, preventing N+1 queries.
- Moving average score is calculated cumulatively:
    moving_average_score = round(sum(running_scores) / len(running_scores), 2)
- Trajectory per attempt compares current score against preceding score:
    "improving" if score > previous else "declining" if score < previous else "stable"
- Topic trends group question accuracy per quiz attempt to visualize mastery over time.

Frontend Visualization:
- Pure React 19 SVG implementation with zero external chart library dependencies.
- Normalized coordinate mapping scales scores (0-100%) to responsive SVG viewBox dimensions.
- Dual-line visualization: solid primary line for actual scores, dashed secondary line
  for smoothed moving average trend.
- Hoverable nodes display comprehensive attempt details in floating tooltip card.

4. SCHEMAS & DATA CONTRACTS ADDED
--------------------------------------------------------------------------------
In `backend/app/schemas.py`:

```python
class LearningProgressPoint(BaseModel):
    attempt_id: int
    quiz_id: int
    quiz_title: str
    completed_at: datetime
    score: int
    accuracy_percentage: float
    correct_answers: int
    total_questions: int
    duration_seconds: int | None = None
    moving_average_score: float
    trajectory: Literal["improving", "declining", "stable"]


class TopicProgressPoint(BaseModel):
    completed_at: datetime
    quiz_id: int
    quiz_title: str
    correct_answers: int
    total_questions: int
    accuracy_percentage: float


class TopicProgressTrend(BaseModel):
    subject: str
    topic: str
    total_attempts: int
    current_accuracy: float
    history: list[TopicProgressPoint]


class LearningProgressResponse(BaseModel):
    student_id: int
    total_quizzes_completed: int
    average_score: float | None = None
    highest_score: int | None = None
    lowest_score: int | None = None
    initial_score: int | None = None
    latest_score: int | None = None
    overall_improvement: float | None = None
    trend_direction: Literal["improving", "declining", "stable", "insufficient_data"]
    timeline: list[LearningProgressPoint]
    topic_trends: list[TopicProgressTrend]
```

5. API ENDPOINTS IMPLEMENTED
--------------------------------------------------------------------------------
1. `GET /analytics/progress`
   `GET /analytics/progress/me`
   `GET /api/v1/analytics/progress`
   `GET /api/v1/analytics/progress/me`
   - Description: Retrieves chronological learning progress, trend metrics, and topic histories for the authenticated user.
   - Auth: Bearer Token required.
   - Response: 200 OK with `LearningProgressResponse`.

2. `GET /users/{student_id}/analytics/progress`
   `GET /api/v1/users/{student_id}/analytics/progress`
   - Description: Retrieves learning progress for a specific student.
   - Auth: Current student (self) or Moderator role required.
   - Status Codes:
     * 200 OK: Valid access.
     * 403 Forbidden: Cross-student unauthorized access attempt.
     * 404 Not Found: Student ID does not exist in the database.
