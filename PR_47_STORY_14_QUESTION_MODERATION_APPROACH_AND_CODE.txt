1. EXECUTIVE OVERVIEW & PROJECT CONTEXT
--------------------------------------------------------------------------------
The Collaborative Study Material & Quiz Platform (CSMQP) is a full-stack, 3-tier
web platform designed for higher education students to share study materials,
collaborate on question banks, conduct real-time multiplayer and practice quizzes,
and evaluate longitudinal topic-level learning analytics.

Architectural Stack:
- Presentation Tier : React + Vite + TypeScript Single Page Application (SPA).
- Service/API Tier  : FastAPI (REST & WebSockets) running on Python 3.12+ (or 3.14).
- Data Tier         : PostgreSQL 15 (relational), SQLAlchemy 2 (ORM), Alembic (migrations),
                      and S3-compatible object storage (RustFS).
- Ingress/Security  : Caddy reverse proxy enforcing TLS 1.3, Bcrypt (cost >= 12)
                      password hashing, HS256 stateless 60-min JWT authentication
                      with token version invalidation, and strict SQL parameter binding.

Milestone Context:
- Foundation (Epic #20 / Story #21): Local Docker infrastructure, TLS proxy, and health checks.
- Epic #1 (Authentication & RBAC, PR #44): 'users' table, registration, login, token revocation.
- Epic #10 (Collaborative Question Bank):
  * Story #11 (Issue #11, PR #45): "Create Questions" (contribute validated MCQs).
  * Story #14 (Issue #14, PR #47): "Question Moderation" (5 Story Points, Sprint 2, Priority: Medium).
  * Objective: Allow authorized moderators to review submitted questions in the shared
    question bank, approve or reject them, ensure rejected questions are excluded from
    published sets, and prevent unauthorized non-moderator users from performing moderation.


2. ACCEPTANCE CRITERIA & HOW EACH WAS FULFILLED
--------------------------------------------------------------------------------
Criteria 1: "Authorized moderators can review submitted questions."
-> Fulfilled:
   - Added endpoint GET /moderation/questions (and GET /api/v1/moderation/questions).
   - Guarded by FastAPI dependency `require_moderator`, which validates JWT authentication
     and asserts `current_user.role == UserRole.MODERATOR`.
   - Returns a structured list of questions awaiting review, with optional filtering
     by `status_filter` (e.g. pending, approved, rejected) and `topic`.

Criteria 2: "Questions can be approved or rejected."
-> Fulfilled:
   - Added endpoint PATCH /questions/{question_id}/moderate (also supports POST).
   - Supports flexible decision input: `{"status": "approved"|"rejected"}` or
     `{"action": "approve"|"reject"}` with an optional feedback `comment`.
   - Also added explicit shortcut endpoints:
     * POST /questions/{question_id}/approve
     * POST /questions/{question_id}/reject?comment=...
   - Atomically records the decision:
     * `question.status` updated to QuestionStatus.APPROVED or QuestionStatus.REJECTED
     * `question.moderator_id` set to the reviewing moderator's user ID
     * `question.moderated_at` set to current UTC timestamp
     * `question.moderation_comment` set to the moderator's explanation/notes.

Criteria 3: "Rejected questions are excluded from published question sets."
-> Fulfilled:
   - Updated GET /questions and GET /questions/search to automatically exclude rejected questions:
     `stmt = stmt.where(Question.status != QuestionStatus.REJECTED)`.
   - Rejection permanently prevents a question from appearing in general queries, practice
     quiz generation, and student search feeds.
   - Verified by dedicated automated test asserting rejected questions do not appear in
     /questions or /questions/search results.

Criteria 4: "Unauthorized users cannot perform moderation actions."
-> Fulfilled:
   - Enforced by `require_moderator` dependency:
     * Unauthenticated requests (no token or invalid token) are rejected with HTTP 401 Unauthorized.
     * Authenticated students (non-moderator accounts) are rejected with HTTP 403 Forbidden
       and the explicit error detail "Moderator privileges required".
   - Verified by automated tests testing missing auth, invalid tokens, and student role attempts.

class QuestionCreate(BaseModel):
    question_text: str = Field(min_length=1)
    options: list[str] = Field(min_length=4, max_length=4)
    correct_answer_index: int = Field(ge=0)
    topic: str = Field(min_length=1)
    difficulty: Literal["easy", "medium", "hard"] = "medium"
    explanation: str | None = None

    @field_validator("question_text", "topic", mode="before")
    @classmethod
    def strip_required_text(cls, value: object) -> object:
        if isinstance(value, str):
            return value.strip()
        return value

    @field_validator("question_text", "topic")
    @classmethod
    def reject_blank_text(cls, value: str) -> str:
        if not value:
            raise ValueError("must not be blank")
        return value

    @field_validator("options", mode="before")
    @classmethod
    def strip_options(cls, value: object) -> object:
        if isinstance(value, list):
            return [option.strip() if isinstance(option, str) else option for option in value]
        return value

    @field_validator("options")
    @classmethod
    def reject_blank_options(cls, value: list[str]) -> list[str]:
        if any(not option for option in value):
            raise ValueError("options must not be blank")
        return value

    @model_validator(mode="after")
    def correct_answer_is_an_option(self) -> "QuestionCreate":
        if self.correct_answer_index >= len(self.options):
            raise ValueError("correct_answer_index must refer to an option")
        return self


class ModerateQuestionRequest(BaseModel):
    action: Literal["approve", "reject"] | None = None
    status: Literal["approved", "rejected"] | None = None
    comment: str | None = None

    @model_validator(mode="after")
    def resolve_decision(self) -> "ModerateQuestionRequest":
        if self.action is None and self.status is None:
            raise ValueError(
                "Must provide either 'action' ('approve'|'reject') or 'status' ('approved'|'rejected')"
            )
        if self.action is not None and self.status is None:
            self.status = "approved" if self.action == "approve" else "rejected"
        return self

@app.post(
    "/auth/register",
    response_model=RegistrationResponse,
    status_code=status.HTTP_201_CREATED,
)
def register(details: RegistrationRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    if db.scalar(select(User).where(User.email == email)) is not None:
        raise HTTPException(status_code=409, detail="An account with this email already exists")

    user = User(email=email, password_hash=hash_password(details.password))
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"message": "Registration successful", "user": user}


@app.post("/auth/login", response_model=TokenResponse)
def login(details: LoginRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    user = db.scalar(select(User).where(User.email == email))
    if user is None or not verify_password(details.password, user.password_hash):
        raise HTTPException(status_code=401, detail="Incorrect email or password")

    return {"access_token": create_access_token(user), "token_type": "bearer"}

@app.patch("/questions/{question_id}/moderate", response_model=QuestionResponse)
@app.post(
    "/questions/{question_id}/moderate",
    response_model=QuestionResponse,
    include_in_schema=False,
)
@app.post(
    "/api/v1/questions/{question_id}/moderate",
    response_model=QuestionResponse,
    include_in_schema=False,
)
def moderate_question(
    question_id: int,
    decision: ModerateQuestionRequest,
    moderator: User = Depends(require_moderator),
    db: Session = Depends(get_db),
):
    """Approve or reject a question. Restricted to authorized moderators."""
    question = db.get(Question, question_id)
    if question is None:
        raise HTTPException(status_code=404, detail="Question not found")

    target_status = (
        QuestionStatus.APPROVED
        if decision.status == "approved" or decision.action == "approve"
        else QuestionStatus.REJECTED
    )
    question.status = target_status
    question.moderator_id = moderator.id
    question.moderated_at = datetime.now(UTC)
    question.moderation_comment = decision.comment

    db.commit()
    db.refresh(question)
    return question

        await websocket.close(code=1008)
        return

    try:
        while True:
            message = await websocket.receive_text()
            await websocket.send_text("pong" if message == "ping" else "Send ping")
    except WebSocketDisconnect:

def test_rejected_questions_excluded_from_published_sets(test_setup):
    client, _, _, student_token, _, moderator_token = test_setup

    # Create 3 questions
    q_good = client.post(
        "/questions",
        json=question_payload(question_text="Good question", topic="Algorithms"),
        headers={"Authorization": f"Bearer {student_token}"},
    ).json()

    q_bad = client.post(
        "/questions",
        json=question_payload(question_text="Bad question", topic="Algorithms"),
        headers={"Authorization": f"Bearer {student_token}"},
    ).json()

    # Moderator approves q_good and rejects q_bad
    client.post(
        f"/questions/{q_good['id']}/approve",
        headers={"Authorization": f"Bearer {moderator_token}"},
    )
    client.post(
        f"/questions/{q_bad['id']}/reject",
        headers={"Authorization": f"Bearer {moderator_token}"},
    )

    # 1. Query /questions list: rejected question MUST be excluded
    list_resp = client.get("/questions?topic=Algorithms")
    assert list_resp.status_code == 200
    returned_ids = [item["id"] for item in list_resp.json()]
    assert q_good["id"] in returned_ids
    assert q_bad["id"] not in returned_ids, "Rejected question must not appear in published list"

    # 2. Search /questions/search: rejected question MUST be excluded
    search_resp = client.get("/questions/search?topic=Algorithms")
    assert search_resp.status_code == 200
    search_ids = [item["id"] for item in search_resp.json()]
    assert q_good["id"] in search_ids
    assert q_bad["id"] not in search_ids, "Rejected question must not appear in search results"


def test_unauthorized_users_cannot_perform_moderation(test_setup):
    client, _, student, student_token, _, _ = test_setup

    q = client.post(
        "/questions",
        json=question_payload(question_text="Moderation auth test question"),
        headers={"Authorization": f"Bearer {student_token}"},
    ).json()

    # 1. Unauthenticated requests rejected with 401
    resp_noauth_list = client.get("/moderation/questions")
    assert resp_noauth_list.status_code == 401

    resp_noauth_mod = client.patch(
        f"/questions/{q['id']}/moderate",
        json={"status": "approved"},
    )
    assert resp_noauth_mod.status_code == 401

    # 2. Student (non-moderator) requests rejected with 403 Forbidden
    resp_student_list = client.get(
        "/moderation/questions",
        headers={"Authorization": f"Bearer {student_token}"},
    )
    assert resp_student_list.status_code == 403
    assert resp_student_list.json()["detail"] == "Moderator privileges required"

    resp_student_mod = client.patch(
        f"/questions/{q['id']}/moderate",
        json={"status": "approved"},
        headers={"Authorization": f"Bearer {student_token}"},
    )
    assert resp_student_mod.status_code == 403
    assert resp_student_mod.json()["detail"] == "Moderator privileges required"

    resp_student_app = client.post(
        f"/questions/{q['id']}/approve",
        headers={"Authorization": f"Bearer {student_token}"},
    )
    assert resp_student_app.status_code == 403

    resp_student_rej = client.post(
        f"/questions/{q['id']}/reject",
        headers={"Authorization": f"Bearer {student_token}"},
    )
    assert resp_student_rej.status_code == 403
