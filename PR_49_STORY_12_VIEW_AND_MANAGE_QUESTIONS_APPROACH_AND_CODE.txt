1. EXECUTIVE OVERVIEW & PROJECT CONTEXT
--------------------------------------------------------------------------------
The Collaborative Study Material & Quiz Platform (CSMQP) is a full-stack, 3-tier
web platform designed for higher education students to share study materials,
collaborate on question banks, conduct real-time multiplayer and practice quizzes,
and evaluate longitudinal topic-level learning analytics.

Architectural Stack:
- Presentation Tier : React + Vite + TypeScript Single Page Application (SPA).
- Service/API Tier  : FastAPI (REST & WebSockets) running on Python 3.12+ (or 3.14).
- Data Tier         : PostgreSQL 15 (relational), SQLAlchemy 2 (ORM), Alembic (migrations),
                      and S3-compatible object storage (RustFS).
- Ingress/Security  : Caddy reverse proxy enforcing TLS 1.3, Bcrypt (cost >= 12)
                      password hashing, HS256 stateless 60-min JWT authentication
                      with token version invalidation, and strict SQL parameter binding.

Milestone Context:
- Foundation (Epic #20 / Story #21): Local Docker infrastructure, TLS proxy, and health checks.
- Epic #1 (Authentication & RBAC, PR #44): 'users' table, registration, login, token revocation.
- Epic #10 (Collaborative Question Bank):
  * Story #11 (Issue #11, PR #45): "Create Questions" (contribute validated MCQs).
  * Story #14 (Issue #14, PR #47): "Question Moderation" (review queue, approval/rejection).
  * Story #13 (Issue #13, PR #48): "Categorize Questions" (subject/topic/difficulty classification).
  * Story #12 (Issue #12, PR #49): "View and Manage Questions" (3 Story Points, Sprint 1, Priority: High).
  * Objective: Allow students to view available questions, enable creators to view and edit
    their own contributed questions, authorize users (creators/moderators) to delete questions,
    and guarantee changes are saved and reflected across the question bank immediately.


2. ACCEPTANCE CRITERIA & HOW EACH WAS FULFILLED
--------------------------------------------------------------------------------
Criteria 1: "Students can view available questions."
-> Fulfilled:
   - General/published questions viewable via GET /questions and GET /questions/{id}.
   - Personal contribution feed via protected GET /questions/me (and GET /questions/my):
     * Requires authentication (`current_user = Depends(get_current_user)`).
     * Filters by `creator_id == current_user.id`.
     * Returns student's entire question contribution history, including pending, approved,
       and rejected items so they can review their feedback and correct mistakes.
     * Supports filtering by `status_filter`, `subject`, and `topic`.

Criteria 2: "Question creators can edit their own questions."
-> Fulfilled:
   - PATCH /questions/{question_id} (and PUT /questions/{question_id}).
   - Permission guard enforces that only the question's creator or a moderator can edit:
     `if question.creator_id != current_user.id and current_user.role != UserRole.MODERATOR: raise 403 Forbidden`.
   - Supports updating question text, options, answer key, explanation, subject, topic, and difficulty.
   - If a previously rejected question is updated by its creator, its status automatically resets
     to `QuestionStatus.PENDING` with cleared moderation notes, allowing re-review by moderators.

Criteria 3: "Authorized users can delete questions."
-> Fulfilled:
   - Implemented DELETE /questions/{question_id} (and DELETE /api/v1/questions/{question_id}).
   - Added DELETE method to CORS `allow_methods` configuration in FastAPI.
   - Guarded by ownership & role check:
     * Unauthenticated requests are rejected with HTTP 401 Unauthorized.
     * Unauthorized students (not the creator and not a moderator) are rejected with
       HTTP 403 Forbidden ("You can only delete your own questions").
     * The question's creator OR any authorized moderator can delete the question.
   - Successfully deletes the database record and returns `{"message": "Question deleted successfully"}`.
   - Non-existent IDs return HTTP 404 Not Found.

Criteria 4: "Changes are saved and reflected in the question bank."
-> Fulfilled:
   - All edit and deletion operations commit directly to PostgreSQL via SQLAlchemy 2.
   - Edited questions immediately reflect updated prompts, options, and explanations in subsequent
     lookups via GET /questions/{id} and GET /questions.
   - Deleted questions immediately vanish from GET /questions and return HTTP 404 on GET /questions/{id}.

@app.post(
    "/auth/register",
    response_model=RegistrationResponse,
    status_code=status.HTTP_201_CREATED,
)
def register(details: RegistrationRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    if db.scalar(select(User).where(User.email == email)) is not None:
        raise HTTPException(status_code=409, detail="An account with this email already exists")

    user = User(email=email, password_hash=hash_password(details.password))
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"message": "Registration successful", "user": user}

@app.patch("/questions/{question_id}", response_model=QuestionResponse)
@app.put(
    "/questions/{question_id}",
    response_model=QuestionResponse,
    include_in_schema=False,
)
@app.patch(
    "/api/v1/questions/{question_id}",
    response_model=QuestionResponse,
    include_in_schema=False,
)
def update_question(
    question_id: int,
    details: QuestionUpdate,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    """Update a question. Authorized to the question creator or a moderator."""
    question = db.get(Question, question_id)
    if question is None:
        raise HTTPException(status_code=404, detail="Question not found")

    if question.creator_id != current_user.id and current_user.role != UserRole.MODERATOR:
        raise HTTPException(status_code=403, detail="You can only update your own questions")

    # Options and correct_answer_index validation
    new_options = details.options if details.options is not None else question.options
    new_correct_index = (
        details.correct_answer_index
        if details.correct_answer_index is not None
        else question.correct_answer_index
    )
    if new_correct_index >= len(new_options):
        raise HTTPException(
            status_code=422,
            detail="correct_answer_index must refer to an option",
        )

    # Content updates
    if details.question_text is not None:
        question.question_text = details.question_text
    if details.options is not None:
        question.options = details.options
    if details.correct_answer_index is not None:
        question.correct_answer_index = details.correct_answer_index
    if details.explanation is not None:
        question.explanation = details.explanation

    # Categorization updates (preserved if None in payload)
    if details.subject is not None:
        question.subject = details.subject
    if details.topic is not None:
        question.topic = details.topic
    if details.difficulty is not None:
        question.difficulty = details.difficulty

    # If a previously rejected question is updated by its creator, reset to pending for re-review
    if question.status == QuestionStatus.REJECTED and current_user.role != UserRole.MODERATOR:
        question.status = QuestionStatus.PENDING
        question.moderator_id = None
        question.moderated_at = None
        question.moderation_comment = None

    db.commit()
    db.refresh(question)
    return question

    include_in_schema=False,

def moderate_question(
    question_id: int,
    decision: ModerateQuestionRequest,
    moderator: User = Depends(require_moderator),
    db: Session = Depends(get_db),
):
    """Approve or reject a question. Restricted to authorized moderators."""
    question = db.get(Question, question_id)
    if question is None:
        raise HTTPException(status_code=404, detail="Question not found")

    target_status = (
        QuestionStatus.APPROVED
        if decision.status == "approved" or decision.action == "approve"
        else QuestionStatus.REJECTED
    )
    question.status = target_status
    question.moderator_id = moderator.id
    question.moderated_at = datetime.now(UTC)
    question.moderation_comment = decision.comment

    db.commit()
    db.refresh(question)
    return question

        await websocket.close(code=1008)
        return

    await websocket.accept()
    try:
        while True:

            await websocket.send_text("pong" if message == "ping" else "Send ping")
    except WebSocketDisconnect:

def make_question(client, token, **overrides):
    payload = {
        "question_text": "Original Question Text?",
        "options": ["A", "B", "C", "D"],
        "correct_answer_index": 0,
        "subject": "Computer Science",
        "topic": "Algorithms",
        "difficulty": "easy",
        "explanation": "Original explanation",
    }
    payload.update(overrides)
    response = client.post(
        "/questions",
        json=payload,
        headers={"Authorization": f"Bearer {token}"},

    return response.json()

def test_authorized_users_can_delete_questions(test_setup):
    client, SessionLocal, student1, t1, student2, t2, moderator, tm = test_setup

    q1 = make_question(client, t1, question_text="Delete by author")
    q2 = make_question(client, t1, question_text="Delete by moderator")

    # 1. Unauthorized student cannot delete author's question
    forbid_del = client.delete(
        f"/questions/{q1['id']}",
        headers={"Authorization": f"Bearer {t2}"},
    )
    assert forbid_del.status_code == 403
    assert forbid_del.json()["detail"] == "You can only delete your own questions"

    # 2. Unauthenticated request cannot delete
    unauth_del = client.delete(f"/questions/{q1['id']}")
    assert unauth_del.status_code == 401

    # 3. Creator deletes their own question
    del_res1 = client.delete(
        f"/questions/{q1['id']}",
        headers={"Authorization": f"Bearer {t1}"},
    )
    assert del_res1.status_code == 200
    assert del_res1.json()["message"] == "Question deleted successfully"

    # Confirm deletion reflected in question bank
    assert client.get(f"/questions/{q1['id']}").status_code == 404
    with SessionLocal() as session:
        assert session.get(Question, q1["id"]) is None

    # 4. Moderator can delete any question
    del_res2 = client.delete(
        f"/questions/{q2['id']}",
        headers={"Authorization": f"Bearer {tm}"},
    )
    assert del_res2.status_code == 200
    assert client.get(f"/questions/{q2['id']}").status_code == 404
