1. EXECUTIVE OVERVIEW & PROJECT CONTEXT
--------------------------------------------------------------------------------
The Collaborative Study Material & Quiz Platform (CSMQP) is a full-stack, 3-tier
web platform designed for higher education students to share study materials,
collaborate on question banks, conduct real-time multiplayer and practice quizzes,
and evaluate longitudinal topic-level learning analytics.

Architectural Stack:
- Presentation Tier : React + Vite + TypeScript Single Page Application (SPA).
- Service/API Tier  : FastAPI (REST & WebSockets) running on Python 3.12+ (or 3.14).
- Data Tier         : PostgreSQL 15 (relational), SQLAlchemy 2 (ORM), Alembic (migrations),
                      and S3-compatible object storage (RustFS).
- Ingress/Security  : Caddy reverse proxy enforcing TLS 1.3, Bcrypt (cost >= 12)
                      password hashing, HS256 stateless 60-min JWT authentication
                      with token version invalidation, and strict SQL parameter binding.

Milestone Context:
- Foundation (Epic #20 / Story #21): Local Docker infrastructure, TLS proxy, and health checks.
- Epic #1 (Authentication & RBAC, PR #44): 'users' table, registration, login, token revocation.
- Epic #10 (Collaborative Question Bank):
  * Story #11 (Issue #11, PR #45): "Create Questions" (contribute validated MCQs).
  * Story #14 (Issue #14, PR #47): "Question Moderation" (review queue, approval/rejection).
  * Story #13 (Issue #13, PR #48): "Categorize Questions" (3 Story Points, Sprint 2, Priority: Medium).
  * Objective: Allow questions to be categorized by subject, topic, and difficulty, enable
    students to filter questions by category, and guarantee that categorization is preserved
    when questions are updated.


2. ACCEPTANCE CRITERIA & HOW EACH WAS FULFILLED
--------------------------------------------------------------------------------
Criteria 1: "Questions can be assigned a subject and topic."
-> Fulfilled:
   - Added `subject: Mapped[str] = mapped_column(String(100), default="General")` to `Question` model.
   - Indexed via `Index("ix_questions_subject", "subject")` and `Index("ix_questions_topic", "topic")`.
   - Updated `QuestionCreate` Pydantic schema to validate `subject` (min_length=1, whitespace-stripped).
   - Migrated database schema via Alembic revision `20261101_0004_add_question_subject_and_category_indexes`.

Criteria 2: "Questions support difficulty classification."
-> Fulfilled:
   - Fully enforced in `QuestionCreate` schema: `Literal["easy", "medium", "hard"]`.
   - Database column `difficulty` indexed with `Index("ix_questions_difficulty", "difficulty")`.
   - Rejects invalid difficulties (e.g. "expert") with HTTP 422 Unprocessable Entity.

Criteria 3: "Students can filter questions by category."
-> Fulfilled:
   - GET /questions and GET /questions/search support multi-category query filters:
     * `subject=...` (filters by subject name or course tag)
     * `topic=...` (filters by specific topic)
     * `difficulty=...` (filters by easy, medium, hard)
     * `category=...` (broad category match matching either subject or topic)
     * Combinations (e.g. `subject=Databases&difficulty=easy`)
   - Added GET /questions/categories endpoint returning distinct subjects, topics, and difficulties.
   - Preserves moderation filter excluding rejected questions from published sets.

Criteria 4: "Categorization is preserved when questions are updated."
-> Fulfilled:
   - Implemented PATCH /questions/{question_id} (and PUT /questions/{question_id}).
   - When updating question prompt, options, or explanation, if `subject`, `topic`, or `difficulty`
     are omitted from the payload, their existing values remain untouched.
   - Enforces creator/moderator authorization check: foreign students attempting to update
     another student's question receive HTTP 403 Forbidden ("You can only update your own questions").
   - Validates option bounds against `correct_answer_index` during updates.

class QuestionCreate(BaseModel):
    question_text: str = Field(min_length=1)
    options: list[str] = Field(min_length=4, max_length=4)
    correct_answer_index: int = Field(ge=0)
    subject: str = Field(default="General", min_length=1)
    topic: str = Field(min_length=1)
    difficulty: Literal["easy", "medium", "hard"] = "medium"
    explanation: str | None = None

    @field_validator("question_text", "subject", "topic", mode="before")
    @classmethod
    def strip_required_text(cls, value: object) -> object:
        if isinstance(value, str):
            return value.strip()
        return value

    @field_validator("question_text", "subject", "topic")
    @classmethod
    def reject_blank_text(cls, value: str) -> str:
        if not value:
            raise ValueError("must not be blank")
        return value

    @field_validator("options", mode="before")
    @classmethod
    def strip_options(cls, value: object) -> object:
        if isinstance(value, list):
            return [option.strip() if isinstance(option, str) else option for option in value]
        return value

    @field_validator("options")
    @classmethod
    def reject_blank_options(cls, value: list[str]) -> list[str]:
        if any(not option for option in value):
            raise ValueError("options must not be blank")
        return value

    @model_validator(mode="after")
    def correct_answer_is_an_option(self) -> "QuestionCreate":
        if self.correct_answer_index >= len(self.options):
            raise ValueError("correct_answer_index must refer to an option")
        return self

    action: Literal["approve", "reject"] | None = None
    status: Literal["approved", "rejected"] | None = None
    comment: str | None = None

    @model_validator(mode="after")
    def resolve_decision(self) -> "ModerateQuestionRequest":
        if self.action is None and self.status is None:
            raise ValueError(
                "Must provide either 'action' ('approve'|'reject') or 'status' ('approved'|'rejected')"

        if self.action is not None and self.status is None:
            self.status = "approved" if self.action == "approve" else "rejected"
        return self

@app.post(
    "/auth/register",
    response_model=RegistrationResponse,
    status_code=status.HTTP_201_CREATED,
)
def register(details: RegistrationRequest, db: Session = Depends(get_db)):
    email = str(details.email).lower()
    if db.scalar(select(User).where(User.email == email)) is not None:
        raise HTTPException(status_code=409, detail="An account with this email already exists")

    user = User(email=email, password_hash=hash_password(details.password))
    db.add(user)
    db.commit()
    db.refresh(user)
    return {"message": "Registration successful", "user": user}

        raise HTTPException(status_code=401, detail="Incorrect email or password")

    return {"access_token": create_access_token(user), "token_type": "bearer"}

@app.patch("/questions/{question_id}", response_model=QuestionResponse)
@app.put(
    "/questions/{question_id}",
    response_model=QuestionResponse,
    include_in_schema=False,
)
@app.patch(
    "/api/v1/questions/{question_id}",
    response_model=QuestionResponse,
    include_in_schema=False,
)
def update_question(
    question_id: int,
    details: QuestionUpdate,
    current_user: User = Depends(get_current_user),
    db: Session = Depends(get_db),
):
    """Update a question. Categorization (subject, topic, difficulty) is preserved unless updated."""
    question = db.get(Question, question_id)
    if question is None:
        raise HTTPException(status_code=404, detail="Question not found")

    if question.creator_id != current_user.id and current_user.role != UserRole.MODERATOR:
        raise HTTPException(status_code=403, detail="You can only update your own questions")

    # Options and correct_answer_index validation
    new_options = details.options if details.options is not None else question.options
    new_correct_index = (
        details.correct_answer_index
        if details.correct_answer_index is not None
        else question.correct_answer_index
    )
    if new_correct_index >= len(new_options):
        raise HTTPException(
            status_code=422,
            detail="correct_answer_index must refer to an option",
        )

    # Content updates
    if details.question_text is not None:
        question.question_text = details.question_text
    if details.options is not None:
        question.options = details.options
    if details.correct_answer_index is not None:
        question.correct_answer_index = details.correct_answer_index
    if details.explanation is not None:
        question.explanation = details.explanation

    # Categorization updates (preserved if None in payload)
    if details.subject is not None:
        question.subject = details.subject
    if details.topic is not None:
        question.topic = details.topic
    if details.difficulty is not None:
        question.difficulty = details.difficulty

    db.commit()
    db.refresh(question)
    return question

def moderate_question(
    question_id: int,
    decision: ModerateQuestionRequest,
    moderator: User = Depends(require_moderator),
    db: Session = Depends(get_db),
):
    """Approve or reject a question. Restricted to authorized moderators."""
    question = db.get(Question, question_id)
    if question is None:
        raise HTTPException(status_code=404, detail="Question not found")

    target_status = (
        QuestionStatus.APPROVED
        if decision.status == "approved" or decision.action == "approve"
        else QuestionStatus.REJECTED
    )
    question.status = target_status
    question.moderator_id = moderator.id
    question.moderated_at = datetime.now(UTC)
    question.moderation_comment = decision.comment

    db.commit()
    db.refresh(question)
    return question

async def websocket_health(websocket: WebSocket):
    origin = websocket.headers.get("origin")
    if origin is not None and origin not in frontend_origins:
        await websocket.close(code=1008)
        return

    await websocket.accept()
    try:
        while True:
            message = await websocket.receive_text()
            await websocket.send_text("pong" if message == "ping" else "Send ping")
    except WebSocketDisconnect:
        pass
